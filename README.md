## 🌟 Overview

Movio brings together a clean, user-friendly interface with real-time data from the TMDB API. It allows users to browse what’s trending, see popular and top-rated movies, keep up with upcoming releases, and search for their favorite films in seconds.

## ✨ Key Features

- Browse now-playing movies on the home screen
- Explore Popular, Top Rated, and Upcoming categories
- Search movies directly from the navigation bar
- Open detailed movie pages with full movie information
- Toggle between light and dark themes
- Responsive layout for desktop and mobile screens
- Modern, polished UI built with Tailwind CSS

## 🧩 Tech Stack

- React
- React Router DOM
- Tailwind CSS
- TMDB API
- JavaScript

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Add your TMDB API token

Create a `.env` file in the project root and add:

```bash
REACT_APP_TOKEN=your_tmdb_access_token
```

### 3. Run the app locally

```bash
npm start
```

Then open:

```text
http://localhost:3000
```
